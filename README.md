# Nammude Sarkar

A Vercel-ready Next.js website for a citizen-friendly Kerala government clarity dashboard.

## Built from the uploaded database

- `ministers.csv`
- `reforms_policy_tracker.csv`
- Cabinet org-chart image asset

## Pages included

- Home landing page
- Ministers directory with filters
- Minister profile pages
- Ministries directory
- Reforms tracker with filters
- Cabinet decisions page placeholder
- Contact directory / citizen issue finder
- Timeline
- About / methodology

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repo in Vercel.
3. Framework preset: Next.js.
4. Deploy.

## Important public launch note

This build uses the uploaded seed database. Before making it public, verify all contact details, official photos, portfolios, and policy entries against official sources.
